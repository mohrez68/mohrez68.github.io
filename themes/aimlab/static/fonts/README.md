# Fonts

Self-hosted variable fonts. All three families are licensed under the SIL Open Font License 1.1.

- **Newsreader** — Production Type / Google Fonts. Latin, weights 400–800, roman and italic.
  Source: `https://github.com/productiontype/Newsreader`
- **Source Sans 3** — Adobe. Latin, weights 300–800, roman and italic.
  Source: `https://github.com/adobe-fonts/source-sans`
- **Vazirmatn** — Saber Rastikerdar. Arabic/Persian and Latin, weights 100–900.
  Source: `https://github.com/rastikerdar/vazirmatn`

Files were downloaded from the Fontsource and Vazirmatn npm distributions and are served from `/fonts/`.
